About this directory Winverse
What is this?
This website is a directory of alternative interfaces, instances and clients for YouTube.

The design is inspired by the classic 2011–2013 YouTube website.

The directory is generated from one JavaScript database, so entries only need to be added once.
Important
Public instances can disappear, change domains, or stop working without warning. Links are community resources rather than permanent guarantees.
Why though?
1. Schools can block YouTube, even educational content. Using these does not mean you are allowed to bypass a school's rules.

2. Some people don't like ads or tracking. Communities have built many alternative frontends for that reason.

3. Some people want nostalgia. Projects such as YT2009 recreate the look and feel of older YouTube.
